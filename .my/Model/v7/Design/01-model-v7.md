# The AI Psychological Adaptation Model — Version 7

A descriptive framework for how people with an established professional identity respond psychologically when a machine begins to do the thing their identity was built around.

This document is the entry point. It states what the model is, what it claims, who it applies to, and — resolving a tension that ran under every prior version — whether it is describing behaviour or recommending it.

## What the model is

Three things stacked together.

**A vocabulary.** Names for recognisable patterns: Identity Shock, Scope Boundary, Overuse, Integrated Practice. Once the names exist, two people can say "she is in Guarded Evaluation about her drafting but Calibrated Use about her correspondence" and agree on what was meant. This is the part of the model that already works.

**A graph of positions.** Nodes that describe where a person currently sits with respect to one domain, and edges that describe which positions tend to follow which. The edges are tendencies observed in accounts and conversation, not measured probabilities.

**A set of modulating axes.** Properties that change how intensely a position is experienced without changing which position it is. Identity Stakes, Delegation Level, Delegation Ceiling, and — new in V7 — Verification Burden.

## What the model claims, precisely

The model makes four claims. They are listed here so a critic knows exactly what to attack.

1. **Identity threat, not utility, drives the difficult positions.** Technology Acceptance Model reasoning (perceived usefulness, perceived ease of use) predicts adoption but not distress. This model claims that when the replicated skill is central to self-concept, adoption behaviour becomes a poor guide to psychological position, and a second dimension is required.
2. **Position is per-domain, not per-person.** The same individual holds different positions simultaneously across different areas of their work. Any assessment that produces a single label for a whole person has made a category error.
3. **The graph is non-linear and re-entrant.** Regression is a normal edge, not a failure. People traverse the graph repeatedly because the environment keeps changing, not because they are unstable.
4. **Intensity and position are independent.** Two people in the same position with different Identity Stakes are having measurably different experiences. Intensity is not a proxy for position, and position is not a proxy for intensity.

## What the model does not provide

- **Causal mechanisms.** The mechanism anchors throughout are vocabulary borrowed from adjacent literature to locate each position in existing thinking. They are not tested causes. Knowing that Identity Shock is conceptually adjacent to self-efficacy collapse says what kind of thing it is; it does not say what produces it.
- **Transition probabilities.** The graph says which edges exist, not how often they are taken or how long a position is occupied.
- **A diagnostic instrument.** No validated test places a person in a position. [20-testing.md](20-testing.md) describes what it would take to build one.
- **A treatment protocol.** The model can inform a trained practitioner's judgement. It does not replace it.

## Descriptive or prescriptive — resolved

Prior versions claimed to be purely descriptive while shipping a sustainability ranking that unmistakably graded the positions as better and worse. This was incoherent, and it is the root of several reviewer objections. V7 resolves it explicitly.

**The model is descriptive. The ranking is editorial and separately labelled.**

Concretely:

- **The model layer** — positions, edges, axes, properties — contains no evaluative language. No position is described as healthy, unhealthy, mature, or regressed. Overuse is a description of a usage pattern and its drivers, not a criticism. Burnout is a description of withdrawal after cost exceeded value, not a failure grade.
- **The editorial layer** — one clearly marked annex — states which positions the author considers sustainable and why. It is signed opinion. A practitioner may use it, argue with it, or discard it without touching the model.
- **The model never names a target position.** There is no correct destination. A person who reaches a stable Scope Boundary in their core craft and stays there for a decade has not failed at anything. A person in Integrated Practice is not further along.

This resolution has a cost worth stating: it makes the model less immediately actionable. A practitioner who wants to be told what to aim for will not find it here. That is the intended trade. The alternative — an implicit ranking that masquerades as description — is worse, because it smuggles the author's values into what looks like an empirical map.

**The single rule that follows:** the model is for understanding where a person is. It is not for engineering where they go next. Using position labels to justify pushing someone through a transition inverts the model's purpose.

## Positions, not stages

V6 called these *states* while numbering them like *stages*, and readers correctly read the ladder that the numbering implied. V7 removes the numbering entirely (see [02-identifiers.md](02-identifiers.md)) and uses the word **position** in prose, retaining *state* only where graph terminology requires it.

The distinction matters:

| | Stages | Positions |
| --- | --- | --- |
| **Order** | Earlier ones precede later ones | No required order |
| **Direction** | Broadly one-way | Entered, left, re-entered freely |
| **Regression** | Unusual, often treated as failure | Routine, named, expected |
| **Implied goal** | The late ones | None |

The forward-flavoured shape of the graph is a consequence of how people typically encounter AI — first contact does tend to precede everything else — not a developmental claim. Beyond first contact, the shape is a web.

## Scope

The model's full machinery applies to **people who built a professional identity in a skill domain before AI could perform that skill**, and who still have a viable position in an AI-collaborative form of that work.

Three conditions:

- **Prior investment.** Enough time in the domain to have formed expectations about their own competence.
- **Identity engagement.** The skill is part of how the person understands themselves professionally, not merely something they do.
- **Economic viability.** Some version of the role survives. Where viability is gone, the model routes to Structural Displacement and stops claiming to explain the rest.

### Cohort, not exclusion

V6 excluded AI-native users from scope. By V7 this exclusion has become impractical: people who formed their professional identity alongside or after capable AI are now colleagues, not a future population. V7 replaces the exclusion with a **cohort property** recorded per person:

| Cohort | Definition | Model applicability |
| --- | --- | --- |
| **Pre-AI formation** | Professional identity formed before AI could perform the core skill | Full machinery. The model was built for this cohort. |
| **Concurrent formation** | Identity formed while AI capability was arriving in the domain | Partial. Disruption family applies unevenly; the person may never have had a clean pre-AI baseline to lose. |
| **AI-native formation** | Identity formed with AI capability already present and assumed | Vocabulary transfers; the Disruption family largely does not. Identity Shock requires a baseline competence to be threatened. |

**New in V7 —** The cohort property is untested. Its practical claim is that the Disruption family (Identity Shock, Scope Boundary) is cohort-dependent while the Working family (Calibrated Use, Overuse, Integrated Practice) is not. **Testable —** see [20-testing.md](20-testing.md).

### Still out of scope

These populations are not less important. They are excluded because the model's vocabulary — identity-protection under capability replication — would misdiagnose them.

- **Involuntary exposure.** People who are *subjects* of AI rather than users of it: filtered by hiring systems, graded by algorithms, assessed by claims models. There is no delegation decision, so there is no First Contact in the model's sense. This population needs a different framework.
- **Assistive use and cognitive disability.** Where AI supplies a capability the person never had unassisted, the assistive-versus-competitive line the model depends on collapses. A dyslexic writer using AI to edit experiences it as access and as replication simultaneously. The model has no vocabulary for the dual role.
- **Non-knowledge domains.** Physical care, manual trades, and routine service face economic replacement without identity replication. The threat is real and the mechanism is different.
- **Relational and companion AI use.** A different phenomenon with a different literature.

## Epistemic status

This model is a **speculative conceptual framework under construction**. No claim in it has been empirically validated. The positions are written as concrete descriptions so that they are specific enough to be wrong.

Markers used throughout:

- **(no marker)** — well-grounded but unvalidated.
- **Conjecture —** offered as a useful frame; not observed.
- **Testable —** a defined study could confirm or refute this.
- **New in V7 —** introduced after V6; no review cycle; least settled.

A model can be useful before it is tested. It supplies language for conversations that previously had none, and a map for practitioners trying to orient. It cannot supply confidence about any individual, and it must not be presented as if it can.
